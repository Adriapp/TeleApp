Installation & Setup

Installation

git clone https://github.com/Adriapp/TeleApp

Configuration Steps

Create a bot on Telegram

Open Telegram, search for @BotFather, send /newbot and follow the instructions. You'll receive an API token.

Create your bot file

Create a PHP file on your HTTPS server:

<?php
include 'bot.php';
$bot = new Bot('YOUR_BOT_TOKEN');

// Your bot logic here

Set the webhook

Via PHP code:

$bot->setWebhook(false, 'https://yourdomain.com/path/to/index.php');

Or via CLI with a self-signed certificate:

php setWebhook.php /path/to/cert.crt BOT_TOKEN domain.com/path/to/bot.php

Practical Examples

Echo Bot

<?php
include 'bot.php';
$bot = new Bot('YOUR_BOT_TOKEN');

if (isset($bot->text)) {
    $bot->sendMessage($bot->user_id, $bot->text);
}

Multiple Commands

<?php
include 'bot.php';
$bot = new Bot('YOUR_BOT_TOKEN');

if ($bot->text == '/start') {
    $bot->sendMessage($bot->user_id, 'Welcome! Use /help for commands.');
}
if ($bot->text == '/help') {
    $bot->sendMessage($bot->user_id,
        '<b>Commands:</b>' . PHP_EOL .
        '/start - Start' . PHP_EOL .
        '/help - Help' . PHP_EOL .
        '/info - Info'
    );
}
if ($bot->text == '/info') {
    $bot->sendMessage($bot->user_id,
        'Your ID: <code>' . $bot->user_id . '</code>' . PHP_EOL .
        'Name: ' . $bot->nome
    );
}

Inline Keyboard + Callback

// Send inline keyboard
if ($bot->text == '/menu') {
    $kb = '[{"text":"Option 1","callback_data":"opt1"},{"text":"Option 2","callback_data":"opt2"}]';
    $bot->sendMessage($bot->user_id, 'Choose:', $kb, 'inline');
}

// Handle callback
if (isset($bot->callback_data)) {
    $bot->answerCallbackQuery($bot->callback_query_id, 'You chose: ' . $bot->callback_data);
    $bot->editMessageText($bot->callback_chat_id, $bot->callback_message_id,
        'Selected: <b>' . $bot->callback_data . '</b>');
}

Welcome New Members

if (isset($bot->nuovo_membro_id)) {
    $bot->sendMessage($bot->chat_id,
        'Welcome, <b>' . $bot->nuovo_membro_nome . '</b>!');
}

Group Moderation

// Ban permanently
$bot->kickChatMember($bot->chat_id, $user_id);

// Ban for 24h
$bot->kickChatMember($bot->chat_id, $user_id, time() + 86400);

// Mute user
$bot->restrictChatMember($bot->chat_id, $user_id, ['can_send_messages' => false]);

// Promote to admin
$bot->promoteChatMember($bot->chat_id, $user_id, [
    'can_delete_messages' => true,
    'can_restrict_members' => true
]);

Version 1 vs Version 2 Methods

Some methods have two versions (e.g. sendMessage / sendMessage2):

Version 1 (sendMessage)Version 2 (sendMessage2)
HowHTTP request via cURL, returns responseOutputs JSON via echo (webhook response)
LimitCan be called multiple timesOnly once per request
WhenGeneral purposeFaster for single-action bots

Metodi v1 vs v2

Alcuni metodi hanno due versioni (es. sendMessage / sendMessage2):

Versione 1 (sendMessage)Versione 2 (sendMessage2)
ComeRichiesta HTTP via cURL, restituisce rispostaStampa JSON via echo (risposta al webhook)
LimiteChiamabile piu' volteSolo una volta per richiesta
QuandoUso generalePiu' veloce per bot a singola azione
